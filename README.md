## 🚀 Proyectos destacados

### 🧫 [Plataforma de Gestión de Cepas Bacterianas](https://github.com/Selix2002/App-Cepas-v2) — *en producción*
Plataforma científica con un chat de IA que consulta la base de datos en lenguaje natural. Incluye una auditoría de seguridad propia: defensa contra *prompt injection* y contra inyección de consultas MongoDB, rate limiting anti fuerza bruta con Redis y protección contra *spoofing* de IP.
`React` `TypeScript` `Python` `Litestar` `MongoDB` `Redis` `LLM` · [🌐 Ver plataforma](https://microlabcepas.ulagos.cl/login)

### ☁️ [Librería serverless en AWS con Terraform](https://github.com/Selix2002/Proyecto-app-AWS)
Arquitectura serverless definida como código: API Gateway, Lambda, DynamoDB, Cognito y S3, con IAM de mínimo privilegio. Desarrollada en equipo durante mi pasantía en España.
`AWS` `Terraform` `Lambda` `DynamoDB` `Cognito` `IAM`

### 💳 [Registro automático de gastos bancarios](https://github.com/Selix2002/Movil-app)
Captura notificaciones, correos y cartolas del banco, y las concilia en PostgreSQL. Verifica DMARC contra phishing, usa tokens de dispositivo hasheados y revocables, ingesta idempotente y Row Level Security.
`Supabase` `PostgreSQL` `Deno` `Flutter` `Kotlin`

### 🛡️ [Machine Learning para detección de intrusiones](https://github.com/Selix2002/Topicos-D)
Pipeline completo de ML sobre el dataset **NSL-KDD** para clasificar tráfico de red como normal o anómalo.
`Python` `scikit-learn` `pandas` `Jupyter`

### 📄 [DocPro](https://github.com/Selix2002/DocPro)
App de escritorio para generar cotizaciones e informes en PDF. Credenciales cifradas, Gmail con OAuth 2.0 y CI/CD con GitHub Actions que publica el instalador automáticamente.
`Python` `PySide6` `SQLAlchemy` `GitHub Actions`

### 🍓 [Cómputo paralelo en un cluster de Raspberry Pi](https://github.com/Selix2002/raspberry)
Algoritmo paralelo con MPI desplegado en un cluster Linux de 7 nodos ARM heterogéneos, con NFS compartido.
`C` `MPI` `Linux` `Redes`
